# 🌱 SmartAgri

SmartAgri is a smart agriculture web application that combines modern web technologies and AI to help farmers make better decisions about crops, diseases, fertilizers, irrigation, soil, weather, and farm management.

## 🚀 Features

- 🌾 Crop Recommendation
- 🦠 Plant Disease Detection
- 🧪 Fertilizer Recommendation
- 💧 Smart Irrigation
- 🌱 Soil Analysis
- 🌦️ Weather Information
- 🚜 Farm Management
- 🤖 AI/ML-powered agriculture assistance

## 🛠️ Technologies Used

### Frontend
- React.js
- Vite
- JavaScript
- HTML
- CSS

### Backend
- Node.js
- Express.js
- MongoDB

### AI / Machine Learning
- Python
- Machine Learning
- AI-based prediction models
